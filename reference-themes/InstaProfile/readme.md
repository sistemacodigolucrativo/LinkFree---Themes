# A LinkStack Theme

* Theme Name: InstaProfile
* Theme Version: 1.2.0
* Theme Date: 16/11/2026
* Theme Author: LinkFree Theme Studio (based on PolySleek by JulianPrieber & LinkStack Team)
* Theme Author URI: https://github.com/sistemacodigolucrativo/LinkFree---Themes
* Theme License: MIT
* Source code: https://github.com/sistemacodigolucrativo/LinkFree---Themes

InstaProfile é um tema estático de perfil de links, com linguagem visual inspirada em redes sociais de fotografia: fundo grafite, superfícies escuras em camadas, avatar circular com aro em gradiente, tipografia de sistema, botões rosa/roxo/laranja/azul com texto branco e elementos acessíveis.

## Características
- Base de estrutura derivada de PolySleek (MIT), reescrita para um visual estático.
- Nenhum JavaScript, partículas, keyframes, transições ou animações contínuas.
- Responsivo de 320 px a desktop, controles com altura mínima de 48 px.
- Componentes LinkStack mantidos: foto de perfil, descrição, ícones, botões, compartilhamento.
- Sem fontes proprietárias, logos, marcas ou APIs do Instagram; não há afiliação com Meta.

## Compatibilidade com Default Theme
A aparência é personalizada, mas os elementos do LinkStack continuam com seus handlers: botões, links, ícones, perfil, rodapé, compartilhar, blocos de texto/título/espaçador, formulários e mídias HTML incorporadas. O CSS ajusta imagens, vídeos, iframes e tabelas a telas móveis; não cria novos tipos de blocos. Veja `docs/AUDITORIA-INSTAPROFILE-PARIDADE-DEFAULT.md` no repositório. Valide integrações com serviços externos em homologação.

## Paleta InstaProfile Dark 1.2
- Fundo grafite: `#0D0D12`; cartões: `#1B1A24` e violeta escuro.
- Títulos: branco; descrições: `#D2CFD9`.
- Acentos: rosa `#E44B9A`, violeta, laranja e azul `#8BCFFF`.
- Botões com quatro variações cromáticas de gradientes estáticos; ícones coloridos sem animações.
- Sem dependência de bibliotecas, APIs ou identidade oficial do Instagram/Meta.
