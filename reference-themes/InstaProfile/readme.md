# A LinkStack Theme

* Theme Name: InstaProfile
* Theme Version: 1.0.0
* Theme Date: 16/11/2026
* Theme Author: LinkFree Theme Studio (based on PolySleek by JulianPrieber & LinkStack Team)
* Theme Author URI: https://github.com/sistemacodigolucrativo/LinkFree---Themes
* Theme License: MIT
* Source code: https://github.com/sistemacodigolucrativo/LinkFree---Themes

InstaProfile é um tema estático de perfil de links, com linguagem visual inspirada em redes sociais de fotografia: fundo neutro, cartões brancos, avatar circular com aro em gradiente, tipografia de sistema, links claros e microdetalhes nas cores rosa, violeta e laranja.

## Características
- Base de estrutura derivada de PolySleek (MIT), reescrita para um visual estático.
- Nenhum JavaScript, partículas, keyframes, transições ou animações contínuas.
- Responsivo de 320 px a desktop, controles com altura mínima de 48 px.
- Componentes LinkStack mantidos: foto de perfil, descrição, ícones, botões, compartilhamento.
- Sem fontes proprietárias, logos, marcas ou APIs do Instagram; não há afiliação com Meta.
