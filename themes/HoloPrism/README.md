# Holo Prism

ZIP pronto para o importador do LinkFree-LinkTree (LinkStack).

1. No painel administrativo, acesse Temas e importe HoloPrism.zip.
2. Escolha o tema HoloPrism no seletor.
3. A imagem thumbnail.png é uma pré-visualização do visual do tema.

Dentro do ZIP os arquivos começam em HoloPrism/config.php, sem uma pasta themes/ extra.
Origem: predefinição do arquivo data/studio-projects.json.
Licença informada: MIT. Consulte também o readme.md incluído no pacote.
Compatibilidade de estrutura verificada; teste de execução no servidor ainda recomendado.
