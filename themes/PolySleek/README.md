# PolySleek (Base Auditada)

ZIP pronto para o importador do LinkFree-LinkTree (LinkStack).

1. No painel administrativo, acesse Temas e importe PolySleek.zip.
2. Escolha o tema PolySleek no seletor.
3. A imagem thumbnail.png é uma pré-visualização do visual do tema.

Dentro do ZIP os arquivos começam em PolySleek/config.php, sem uma pasta themes/ extra.
Origem: tema original de reference-themes.

Compatibilidade de estrutura verificada; teste de execução no servidor ainda recomendado.
